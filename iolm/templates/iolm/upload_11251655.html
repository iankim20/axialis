데이터 보안 및 개인정보 보호

Axialis는 업로드된 IOLM 이미지를 분석에 필요한 기간 동안만 임시 보관하며, AI 분석 파이프라인이 완료된 후에는 이미지 파일을 자동으로 삭제합니다.

분석 과정에서 사용하는 OpenAI 기반 비전 모델은 이미지 내용을 학습·재가공용으로 저장하지 않도록 설계된 엔드포인트를 이용합니다. 즉, 업로드된 IOLM 이미지는 모델 재학습이나 2차 활용에 사용되지 않습니다.

추출된 엑셀 데이터는 해당 사용자 계정에서만 다운로드 가능하도록 제공되며, 전송 및 저장 과정에서 암호화된 채널과 안전한 스토리지를 사용합니다.

어떻게 사용하나요?

  1. 1️⃣ EMR 또는 PACS에서 IOLMaster 스타일의 IOLM 이미지를 일괄 다운로드합니다.
  2. 2️⃣ 각 환자·검사별 이미지를 하나의 폴더에 모은 뒤 ZIP으로 압축합니다.
  3. 3️⃣ 로그인 후 ZIP 파일을 업로드하면, 각 이미지에서 OD/OS별 2행씩 데이터를 추출합니다.
  4. 4️⃣ 생성된 엑셀/CSV 파일을 내려받아 통계 분석·연구에 바로 활용합니다.

  • 각 이미지에는 양안 정보(OD/OS)가 함께 보이는 일반적인 IOLMaster 결과 화면이 포함되어야 합니다.
  • 해상도는 너무 낮지 않게 (예: 가로 800px 이상) 저장된 이미지 권장입니다.

Axialis에서 추출하는 주요 변수

IOLMaster 계열 기기에서 공통적으로 제공되는 핵심 지표들을 중심으로 자동 추출합니다.

  • 검사 ID (익명화된 내부 식별자)
  • 검사일 / 검사 시간
  • 눈 구분 (OD / OS)
  • Axial Length (AL)
  • Anterior Chamber Depth (ACD)
  • Lens Thickness (LT)
  • Central Corneal Thickness (CCT, 옵션)
  • K1 / K2, 평균 K
  • Total Keratometry (TK)* 지원 기기에서
  • White-to-White (WTW)
  • SNR / Signal Quality (가능한 경우)
  • Target Refraction / IOL Power (옵션)
  • 기타 연구 목적에 맞게 확장 가능한 부가 지표

실제 추출 변수 구성은 기기 종류와 버전에 따라 일부 달라질 수 있으며,
필요 시 사용자 요청에 따라 커스터마이징이 가능합니다.
